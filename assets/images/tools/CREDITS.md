# Software & Tools logos

Each logo is the trademark of its owner and is shown only to identify software named on the Software & Tools page.

- PNG files: each product's own site icon (favicon), fetched at 128px (smaller where the site only offers a smaller icon)
  via Google's favicon service, e.g. https://www.google.com/s2/favicons?domain=xero.com&sz=128
- SVG files (gmail, google-drive, google-sheets, google-workspace): official logos from Wikimedia Commons
  (Gmail_icon_(2020).svg, Google_Drive_icon_(2020).svg, Google_Sheets_logo_(2014-2020).svg, and Google_"G"_logo.svg for
  Google Workspace, which is the icon Google uses on workspace.google.com).
